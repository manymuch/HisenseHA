# 海信爱家家庭副账号共享配置指引（0 抓包 · 彻底防互踢 · 零门槛）

本指引详细介绍如何通过「海信爱家」官方的**家庭成员共享功能**，为 Home Assistant 配置专属的家庭副账号。该方案**无需任何抓包工具**（0 抓包、0 门槛），即可彻底杜绝手机 App 与 Home Assistant 之间的 MQTT 客户端会话抢占互踢，实现 100% 稳定的实时状态与洗涤完成推送。

---

## 一、为什么要使用家庭副账号？

### 1.1 核心痛点：单账号抢占互踢
- 海信爱家采用阿里云 / 百度智能云物联网核心套件的 MQTT Broker 作为推送中枢。
- 当 Home Assistant 使用与手机 App 完全相同的账号凭据连入 MQTT 服务器时，服务器会检测到相同的设备标识（Client ID）或用户会话。
- 依据标准 MQTT Broker 规范，**后连入的客户端会立即踢掉先连入的客户端**（即“互踢”）。这会导致：
  - Home Assistant 的实时推送频繁断开、重连甚至收不到推送；
  - 手机端 App 弹出“已在其他设备登录”或丢失实时动态。

### 1.2 官方家庭共享方案的核心优势
- **0 抓包（零技术门槛）**：完全不需要使用 Charles、Reqable、Proxyman 等复杂的网络抓包工具，1 分钟在手机 App 界面内直接搞定。
- **完全独立的客户端会话**：手机端登录**主账号 A**，Home Assistant 登录**副账号 B**。两端拥有完全独立的 MQTT Client ID 与长连接通道，同时在线，永不冲突。
- **全量家电设备互通**：依托海信官方的云端家庭共享机制，副账号拥有对家庭内全部智能设备（洗衣机、干衣机、空调、冰箱等）的完整控制与状态读取权限。
- **永久稳定有效**：家庭副账号凭据永久生效，不受手机 App 前台或后台切换的影响。

## 二、详细配置步骤（四步搞定）

```
+-------------------------------------------------------------+
|                      海信爱家云端家庭                        |
|                     (例如："我的家")                        |
+------------------------------+------------------------------+
                               |
            +------------------+------------------+
            |                                     |
            v                                     v
+-----------------------+             +-----------------------+
|      主账号 (用户手机)  |             |     副账号 (HA 专属)   |
|   (手机号: 138xxxx1111)|             |   (手机号: 139xxxx2222)|
|   登录官方手机 App     |             |   登录 Home Assistant |
|   拥有家庭所有权       |             |   角色: 管理员 / 成员  |
+-----------------------+             +-----------------------+
            |                                     |
    MQTT 客户端会话 A                     MQTT 客户端会话 B
  (独立连接，永不冲突)                  (独立连接，永不冲突)
```

### 第一步：准备并注册副账号
1. 准备一个副手机号（可使用家人的手机号，或您个人的副卡、备用手机号）。
2. 在手机端「海信爱家」App 登录界面选择该手机号进行注册或登录。
3. **重要：为副账号设置固定登录密码**：
   > [!IMPORTANT]
   > 许多用户习惯使用短信验证码登录，**但 Home Assistant 接入需要静态账号密码**。
   > 请打开「海信爱家」App，进入 **我的 -> 设置（右上角齿轮）-> 账号与安全 -> 修改密码 / 设置密码**，为该副账号设置一个固定的登录密码。

---

### 第二步：在主账号中添加家庭成员
1. 在手机上登录您绑定了洗衣机/空调/冰箱的**主账号**。
2. 点击底部导航栏 **「我的」**。
3. 找到并点击 **「家庭管理」**（部分版本显示为「我的家庭」）。
4. 点击包含智能家电的目标家庭（例如默认的“我的家”）。
5. 点击 **「成员管理」** -> **「添加成员」**（或「邀请成员」）。
6. 输入**副账号的手机号**：
   - 成员角色建议选择 **「管理员」**（拥有设备的完整控制与联动权限）。
7. 点击发送邀请。

---

### 第三步：副账号接受邀请并确认
1. 在副账号手机上（或在 App 退出主账号临时登录副账号）查看系统通知。
2. 接受加入家庭的邀请。
3. 确认副账号的 App 首页中能正常看到家庭内绑定的所有家电设备（洗衣机、空调、冰箱等），并能正常查看实时状态。

---

### 第四步：在 Home Assistant 中配置集成
1. 打开您的 Home Assistant 控制台。
2. 进入 **设置 -> 设备与服务 -> 添加集成**。
3. 搜索并选择 **Hisense Smart Devices (海信智能设备)**。
4. 在配置弹窗中输入：
   - **用户名**：输入**副账号的手机号**。
   - **密码**：输入在第一步中为副账号设置的**固定登录密码**。
5. 点击提交，选择目标家庭（如“我的家”），勾选需要接入的设备，完成向导。

## 三、效果验证

完成上述配置后：
1. **状态即时同步**：洗衣机开机、关机、切换洗涤程序、调整水温转速时，Home Assistant 秒级感知。
2. **洗完即时提醒**：洗衣程序结束瞬间，Home Assistant 零延迟捕获云端推送，自动触发 `hisense_washer_complete` 总线事件与系统持久化通知。
3. **彻底防互踢**：无论您何时在手机上打开、关闭或后台常驻「海信爱家」App，Home Assistant 的 MQTT 长连接始终保持健康在线，双方互不干扰。

## 四、常见问题解答（FAQ）

### Q1: Home Assistant 登录时提示“登录失败 (invalid_auth)”？
- **排查原因**：副账号密码输入错误，或副账号尚未在海信爱家 App 中设置静态密码。
- **解决方法**：请在手机 App 中用该副账号登录一次，并在 **设置 -> 账号与安全** 中重新设置密码，然后用新密码在 HA 中重试。

### Q2: 登录成功后提示“未找到设备 (no_devices)”或设备列表为空？
- **排查原因**：副账号尚未加入包含设备的家庭，或者被加入到了一个空的家庭中。
- **解决方法**：请主账号打开 App 确认副账号是否已成功加入家庭；若有多个家庭，确保在 HA 配置流的“选择家庭”步骤中选中了设备所在的正确家庭。

### Q3: 使用副账号是否会影响主账号的质保与售后？
- **解答**：完全不会。设备的购买记录、电子发票和官方售后绑定依然归属于主账号。家庭成员共享仅授予家电设备的控制与状态查看权限。
